## Монетизация (обновлено 17.10.2026 — решение после исследования AdSense-санкций)

**AdSense «прямо» недоступен**: Google деактивировал ВСЕ Россия-based AdSense-аккаунты (авг 2024,
Reuters). План «AdSense при ≥5K pv» заменён на **3-канальную модель** (каналы 1-2 работают из РФ без схем):

1. **Donate USDT TRC-20** (приоритет №1) — кнопка в лендинге, выплата через Bybit → рубли. Не зависит
   от санкций; на YMYL-нише «стресс + бесплатный инструмент» донаты реалистичны (WinRAR-эффект)
2. **Affiliate-ссылки** на SEO-страницах (приоритет №2) — вместо баннеров: рекомендации проф-услуг
   (attorneys, reserve-study firms) по партнёрским программам; реклама в виде контента, не баннеров
3. **Рекламные сети с крипто-выплатой** (эксперимент при ≥5K pv, приоритет №3) — Media.net (качество
   выше; нужна зарубежная точка выплат — PayPal/wire) ИЛИ Adsterra/HilltopAds (USDT-выплата, но
   низкосортные форматы: только native-баннеры, БЕЗ popunders — YMYL-аудитору казаться дешёвым нельзя)

**Правила монетизации (не менять):**
- Реклама ТОЛЬКО на SEO/landing/education-страницах — НИКОГДА внутри app.html, print-вью, sample-вью
- ADSLOT-плейсхолдеры в коде остаются: подключение любой сети позже = 1 вставка, не редизайн
- Серые схемы AdSense (чужие имена/адреса) — НЕ используем: Google деактивирует по локации
  с потерей баланса (документированный кейс потери $2,751)
- Триггер запуска монетизации: **≥5000 pv/мес** (безотносительно канала; до того — только Donate)
