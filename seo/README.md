# seo/ — рабочие заметки по SEO estate-ledger

Ведёт агент, читать может человек. Начинать с первых трёх файлов.
Методика: скилл `product-seo` (`~/AppData/Local/hermes/skills/product-seo/`).

| Путь | Что это |
|---|---|
| `site-profile.md` | продукт, кто платит, две кучи тем, решения владельца, где искать данные |
| `change-log.md` | каждое изменение сайта: дата, бэкап, даты проверок, результат |
| `lessons.md` | что сработало и что делать иначе; читать перед каждой новой страницей |
| `product-facts.md` | единственный источник правды о продукте; каждая строка с датой проверки |
| `experiments.md` | одна гипотеза на страницу и её результат |
| `data/` | выгрузки Search Console (не в git) |
| `shots/` | скриншоты проверок (не в git) |

## Как мерить

`node ~/AppData/Local/hermes/skills/product-seo/scripts/measure.mjs --page <url> --date <YYYY-MM-DD> --site sc-domain:estateledger.app --log seo/change-log.md`

Скрипт сравнивает целые недели до и после даты изменения (день изменения исключён)
и применяет правило отката: 21+ дней, клики −30% и позиция всё ещё хуже → откат.

**Для этого сайта правило применимо напрямую**: у estate-ledger нет сезонного цикла.
(У csv-to-json он есть — дедлайн GSTR-1 11-го числа, там measure.mjs без поправки
на фазу цикла даёт ложный результат. См. lessons.md.)

Добавляй строку сюда, когда появляется новый файл или папка.
